# Historical documents

`gpuopt-README.md` is the README of Shivanshu Vats's `gpu_optimization` repository at commit
`c192dd0`, kept unchanged for the record (its design notes and "issues found and fixed" table
are still useful). Its paths (`gpuopt`, `include/gpuopt/…`, `scripts/…`), build instructions
and numbers describe that repository **before** the merge and were measured on a Windows
laptop. Every claim in it was re-run during the integration: see
`docs/audit/INITIAL_AUDIT.md` (e.g. its "48 of 49 Netlib" became 92/93 on the full set,
independently verified). For the current system read the top-level `README.md`,
`docs/ARCHITECTURE.md` and `docs/EVIDENCE.md`.
